Three families do all the work. Tungsten Medium for condensed, vertical headlines that echo the “I” of the logo and the Navigation Portal. Myriad Pro for legible print body copy. Arial for presentations, HTML email and website copy.

Which family you reach for is decided by channel, not by taste. The usage framework in section 04 is the governing table — check it before choosing a face.

03 — Web & presentation · Arial

Arial is universal and versatile. For website copy and email it is the preferred font — not a fallback. Arial Regular, Italic, Bold and Bold Italic all carry website copy and email. Presentations are set in Arial throughout: titles, headers and body copy, in black.

ExceptionLinks & banners

Website link names and online banner headlines stay in the Myriad Pro family: Semibold for emphasis in link names, Condensed and Bold Condensed for link names and online banners.

Web CSS stack — headlines: "Tungsten Medium", "Arial Narrow", sans-serif · body: Arial, "Myriad Pro", sans-serif · print/collateral body: "Myriad Pro", Arial, sans-serif

Correction. An earlier version of this reference described Arial as a fallback for when Myriad Pro cannot be embedded, and put Myriad Pro first in the web body stack. The style guide reverses that: for website content and HTML email, Arial is the specified family and Myriad Pro is reserved for links and banners.

07 — Accessibility

  • Body text never below 14px on mobile; line-height at least 1.5 for paragraphs.
  • Never set long passages in all-caps Tungsten. Reserve it for short headlines — uppercase condensed type slows reading and defeats word-shape recognition.
  • Headline colour is the dark tier of the active set. Dark on light reaches AAA on every brand background; Infosys Blue on white measures 4.50:1, which clears AA for large text only.
  • Body copy at 16px needs 4.5:1. Sapphire Dark on white measures 17.57:1 and Infosys Chrome on white 5.10:1 — both clear it.
  • Do not use Myriad Pro Condensed below 12px in print or 14px on screen; the narrow apertures close up at small sizes.
  • Italics carry emphasis, never meaning on their own. Pair with a word or a label.
  • Set real text, not images of text, wherever the channel allows it.

08 — Licensing

  • Tungsten is licensed from typography.com. Myriad Pro is an Adobe licensed font.
  • External design agencies, film agencies and printers working on Infosys and affiliate projects must license their own copies and execute the project on those licences.
  • Fonts are embedded in Infosys source files as a default function of the software. That embedding does not transfer a licence.
  • Sharing font files is a breach of the licence terms.
