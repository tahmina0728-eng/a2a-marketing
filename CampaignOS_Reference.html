1. System Overview

CampaignOS is a multi-agent AI pipeline that takes a marketing brief (selected via a 7-step wizard UI) and produces a validated brief, creative strategy, and campaign copy — all grounded in real brand guidelines, customer data, and performance benchmarks.

What it does

Input
Marketer selects brand, goal, product, fan truth, audience, channels and budget via a click-based wizard (no typing required)
Brief Validation
AI validates the brief against real brand guidelines, scores the Fan Truth (0-100), flags unrealistic KPIs, checks audience vs CDP data
Creative Strategy
Generates the Big Idea, hero message, messaging pillars, channel priorities and budget allocation based on validated brief
Campaign Copy
Writes short (OOH/KV), medium (social), long (press/editorial) copy variants plus CTA, Instagram caption, and TikTok hook

2. Architecture & Data Flow

Full Pipeline Flow

USER WIZARD (React UI) └── POST /brief-full │ ├── 1. load_brand_context [FUNCTION NODE — zero LLM cost] │ ├── GCS Bucket → logos, fonts, product images (BRAND_ASSETS_MODE=gcs) │ ├── Vertex AI Search → brand guidelines text (SEARCH_MODE=live) │ ├── pgvector → fan truth benchmarks, channel benchmarks │ └── pgvector CDP → Kaggle customer segments (2,216 real customers) │ ├── 2. Briefing Agent [Groq Llama 3.3 70B] │ Input: Brief + all context from load_brand_context │ Output: MachineBrief JSON │ ├── Fan Truth score (Specific/Shared/Special, 0-100) │ ├── KPI flags (OK / AMBITIOUS / UNREALISTIC) │ ├── Brand locks applied │ ├── Brand warnings │ └── Status (READY / NEEDS_REVIEW / INCOMPLETE) │ ├── 3. Strategy Agent [Groq Llama 3.3 70B] │ Input: MachineBrief + brand guidelines │ Output: CreativeStrategy JSON │ ├── Hero message (≤8 words) │ ├── Strategic framework (2-3 sentences) │ ├── Messaging pillars (3-4 key messages) │ ├── Channel priorities (ranked 1-10) │ └── Budget allocation per channel │ └── 4. Copy Agent [Groq Llama 3.3 70B] Input: MachineBrief + CreativeStrategy + brand locks Output: CampaignCopy JSON ├── Short copy: headline ≤6 words (for OOH/KV) ├── Medium copy: headline + subline (for social/display) ├── Long copy: headline + body ≤60 words (for press) ├── CTA: ≤3 words, verb-led ├── Instagram caption with hashtags └── TikTok hook (first 3 seconds)

The seed_kaggle_cdp.py script converts each row into a natural language CRM note, embeds it with SentenceTransformer (all-MiniLM-L6-v2, 384 dimensions), and stores in pgvector for semantic search.

5. Frontend UI Components

7-Step Wizard

1

Brand Selection

Choose brand: McDonald's 🍔 or Rnorr 🥣. Clears product selection when changed.

2

Campaign Goal

6 tile cards: Launch Awareness, Drive Sales, Build Community, Re-engagement, Market Expansion, Custom

3

Product

Brand-specific chip list (Rnorr: stock cubes, bouillon, etc. / McDonald's: McSpicy, Big Mac, etc.)

4

Fan Truth

Brand-specific pre-written truths or "Write your own". Rnorr truths are different from McDonald's truths.

5

Audience

Age groups, interests, market/region chips. Season selection (Spring/Summer/Autumn/Winter/All Year)

6

Channels & KPIs

Channel tiles (Instagram, TikTok, YouTube, OOH, Google Ads, Meta Ads) + success metrics + moment type

7

Budget & Review

Budget cards (£50K to £1M). Campaign name input (min 3 chars to enable Launch). Full brief review.

Results Page — 3 Main Cards

📋 Brief Validation
• SVG circular gauge showing Fan Truth score (color-coded: green ≥75, amber ≥60, red <60)
• PASS/FAIL badge
• Fan truth statement in purple highlight box
• Color-coded KPI rows (✓ OK, ↑ AMBITIOUS, ✗ UNREALISTIC)
• Validation notes
👥 Audience Intelligence
• Profile count (858 Rnorr profiles)
• 4 metric blocks: Avg Income, Meat Spend, Deal Purchases, Web Visits
• Channel chips (Instagram, TikTok, Facebook)
• CRM quote from most similar Kaggle customer
⚡ Pipeline Output
• Campaign name, channels, market, season, budget, moment, audience
• Brief summary in blue quote box
• Brand warnings (if any) in amber

Full-width sections below the cards:

💡 Creative Strategy — gradient card with hero message, strategic framework, cultural context, creative brief, messaging pillars as chips

✍️ Campaign Copy — 3 format cards (green SHORT, blue MEDIUM, amber LONG) + CTA, Instagram, TikTok row

6. Commands Reference

Docker / pgvector

# Start pgvector (port 5433 — avoids conflict with local PostgreSQL on 5432)
cd d:\campaignos\harness
docker compose -f docker-compose.pgvector.yml up -d

# Stop and remove
docker compose -f docker-compose.pgvector.yml down -v

# Enable pgvector extension (run once)
docker exec campaignos-pgvector psql -U campaignos -d marketing -c "CREATE EXTENSION IF NOT EXISTS vector;"

# Check tables
docker exec campaignos-pgvector psql -U campaignos -d marketing -c "\dt"

Data Setup Scripts

cd d:\campaignos\harness

# 1. Create pgvector schema + seed synthetic data
uv run python scripts/setup_pgvector.py

# 2. Load Kaggle CSV into pgvector (2,216 customer records)
#    Requires: scripts/marketing_campaign.csv
uv run python scripts/seed_kaggle_cdp.py

# 3. Upload Kaggle CSV to GCS + BigQuery
uv run python scripts/upload_kaggle_to_bq.py

# 4. Index GCS brand guidelines as RAG chunks
uv run python scripts/index_gcs_guidelines.py

# 5. Pull BigQuery tables into pgvector with embeddings
uv run python scripts/index_bigquery.py

# 6. Create Vertex AI Search app + import GCS documents
uv run python scripts/setup_search.py

# 7. Upload asset manifests to GCS + re-index in Search
uv run python scripts/index_brand_assets.py

# 8. Create BigQuery dataset + tables
uv run python scripts/setup_bigquery.py

# Install uv (Windows)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Known Limitations

IssueCauseWorkaround
Vertex AI Gemini 404 GCP free trial project doesn't have Gemini publisher models enabled in Model Garden Using Groq/LiteLLM instead for all agents
Google AI free tier limit:0 API key from billing-enabled project zeroes free tier quota Groq provides genuinely free tier (14,400 req/day)
HITL gates not persistent Using InMemorySessionService — state lost on restart For production: swap to VertexAiSessionService
Vertex AI Search Standard Edition Extractive answers/segments require Enterprise Edition Using snippets + summary only (Standard Edition compatible)
pgvector port 5433 Local PostgreSQL already occupies port 5432 Docker container mapped to 5433 instead
